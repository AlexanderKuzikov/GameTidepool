# GameTidepool — Glowing Tendril

> Игра: один HTML-файл, Canvas 2D, WebAudio, без сборки и сервера.

## Описание

Ты — сияющий течущий клуб в тихой полости. Плавная клавиатурная навигация, динамические клубы света, кораллы-ловушки, визуальные решетки и дно полости. Собирай свет — счёт растёт, глубина считается с темпом твоих перемещений.

## Открыть

```bash
open D:\GitHub\GameTidepool\index.html
```

Открой файл в браузере — игра запустится напрямую: `file:///D:/GitHub/GameTidepool/index.html`.

## Управление

- `↑ ↓ ← →` или `W A S D` — движение
- `Shift` — ускорение
- `P` — пауза / продолжение
- `R` — рестарт после поражения
